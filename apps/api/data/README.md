# Map data

`kabankalan-barangays.geojson` holds the 32 barangay boundaries of Kabankalan City (PSGC `1804515000`), at medium resolution. Migration `003_kabankalan_barangays.sql` was generated from it.

- **Source:** [faeldon/philippines-json-maps](https://github.com/faeldon/philippines-json-maps), built from OCHA's [COD-AB Philippines boundaries](https://data.humdata.org/dataset/cod-ab-phl).
- **License:** the boundaries are by the National Mapping and Resource Information Authority (NAMRIA) and the Philippine Statistics Authority (PSA), under [CC BY-IGO 3.0](http://creativecommons.org/licenses/by/3.0/igo/legalcode). The app's map shows this credit.
- **Retrieved:** 2026-11-07.
